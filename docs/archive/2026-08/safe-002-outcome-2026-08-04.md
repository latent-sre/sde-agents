## The defect

`execute_approved` reserved the approval nonce, ran the subprocess, then finalized the row. A
crash anywhere in that window left a permanent `reserved` row: replay stayed blocked by the
primary key, but nothing distinguished "in flight" from "crashed" and no operator path existed to
see or close the ambiguity.

## What landed

- **An explicit `unknown` state with recorded origins.** A failure the broker survives marks the
  row `unknown` before re-raising — `dispatch-exception` or `finalization-exception` per the
  phase reached, with `BaseException` caught deliberately so a mid-dispatch Ctrl-C is recorded as
  exactly what it is. A whole-process death leaves `reserved`; `reconcile list` transitions it to
  `unknown` (`stale-reservation`) only past a deadline of `reserved_at + timeout_seconds + 60s
  grace` — conservative, not proof: the bound covers the child process, not a live broker's
  finalization tail, and a broker losing that race fails loudly in `finish()` with the outcome it
  could not record.
- **Deadline-based staleness, deliberately not process-identity.** The rival implementation (PR
  #82) promoted any `reserved` row owned by a different pid; that converts ordinary cross-process
  concurrency — an operator reconciling while a broker runs — into false unknowns, because
  different-pid does not mean dead. The deadline rule detects crashes slower and never
  falsely-unknowns a live reservation.
- **Self-sufficient ledger rows.** `reserve()` copies action, target, argv, timeout, and expiry
  onto the row, so reconciliation lists the exact approved effect without the request/approval
  JSON files, which may not survive the crash. The schema migration is additive-only and
  tolerates concurrent first-contact migration.
- **Key-gated, evidence-bound resolution.** `reconcile resolve` requires the same HMAC key as
  `approve`/`execute`, records one of `executed` / `not-executed` / `indeterminate` — the third
  value exists so an operator who cannot establish the outcome is never forced into a false
  binary — and mints a validated evidence envelope whose limitations name it an attestation, not
  machine proof. Every resolution state is terminal; no path ever frees a nonce.
